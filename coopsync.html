ℹ 結局どうする？

いちばん現実的なのは、Moon Sweepers に公式対応していて、キャラクターの入れ替えも機能に含まれている SaveSync（¥700）です。無料にこだわる場合は、LaneBirmingham 版をテスト用ワールドで試すところから始めます。

3仕組み

coopsync.app 版（公式サイト・規約に書かれていることだけ）

  • 確認済みWindows 10/11 向けの無料デスクトップアプリ（MODではない）。規約に「タイトルバー」「Settings」とあるので、GUI はあると思われます。
  • 確認済みGitHub の OAuth Device Flow でログインし、友人と2人で所有する private リポジトリにセーブを同期します。Git for Windows を別途インストールする必要があります。
  • 確認済みインストール済みの Steam ゲームとセーブを自動で検出します（サイトの記載は「no manual paths」）。
  • 確認済み友人がゲーム中かどうかを表示する機能があります（signal.coopsync.app を使う）。
  • 未確認検出の仕組み、同期のタイミング、競合時の動作、ロック、対応ゲームの一覧、3人以上で使えるか（規約は「2人」と書いている）。

LaneBirmingham 版（ソースで確認）

  • 確認済みTauri（Rust と React）で作られた GUI アプリです。Git と GitHub CLI は、アプリから winget でインストールします。
  • 確認済み共有するセーブ1つにつき、private リポジトリを1つ使います。友人は GitHub の collaborator として招待し、参加用のコードで加わります。
  1. Start Hosting最新を取得して整合性を確認し、zip でバックアップを取ってから、リモートにロックをかけてセーブを反映します。
  2. ゲームを遊ぶこの間、ほかの人はロックがかかっているので、ホストを始められません。
  3. Finish & Publish世代番号を1つ上げて push します。リモートが途中で動いていたら止まります。
  4. （中止するとき）Abort Hosting変更をアップロードせずにロックを外します。

4カスタマイズ性（LaneBirmingham 版・ソースで確認）

確認したいこと結果
設定ファイルで対応ゲームを追加できるかゲームの定義は JSON（src-tauri/game_profiles/*.json）で書きます。ただし include_str! でビルド時にアプリに埋め込まれるので、追加するには再ビルドが必要です。JSON 1つと game_profile.rs の3か所を書き換えます。
セーブフォルダを手動で指定できるかできます。「Custom Folder」で好きなフォルダを選べ、そのフォルダの全ファイルが同期の対象になります。
未対応のゲームを登録できるかCustom Folder で代わりにできます。ただし、ゲームが起動中かどうかの検知はなく、同期の対象を絞ることもできません。
セーブの形式に依存しているか依存していません。ファイルを丸ごとコピーし、ハッシュで確認するだけです。
GitHub での同期部分を他に流用できるかできます。ゲームに依存しない作りになっています。
ゲーム定義（JSON）で設定できる項目
  • save_directories：セーブフォルダの候補（%USERPROFILE% などの変数が使える）
  • save_folder_patterns：ワールドごとのフォルダの見つけ方
  • file_patterns／exclude_patterns：同期するファイル・しないファイル
  • process_name：この exe が起動中は同期をブロックする
  • steam_cloud_conflict：Steam Cloud と競合するかどうか

5Moon Sweepers への適用

セーブデータ

  • 推測保存場所は %USERPROFILE%\AppData\LocalLow\DragDropGames\MoonSweepers\MoonSessions です。第三者の攻略サイト1つに書かれていたもので、公式の資料ではありません。実際のPCで確認してください。
  • 推測同じサイトによると、このフォルダは Steam Cloud の同期対象です。
  • 確認済みワールドは5つのスロットに保存されます（SaveSync 公式ガイド）。
  • 未確認ファイル名、拡張子、1ワールドが何ファイルでできているか、実行ファイル名（exe）。

プレイヤーの識別（いちばん注意が必要）

A のPCで遊んだセーブlocal = A のキャラクター
steam-B = B のキャラクター
→
そのまま B に渡すファイルを丸ごとコピー
→
B がホストするとB が local（A のキャラクター）で遊ぶ

確認済みSaveSync の公式ガイドには、「手作業でセーブを渡して友人がホストすると、元の持ち主のキャラクターで遊ぶことになる」と書かれています。SaveSync はこの入れ替えを自動でしています。

推測LaneBirmingham 版は入れ替えをしないので、このずれがそのまま起きます。coopsync.app 版が入れ替えをするかどうかは未確認です（資料がない）。A があとから参加したときの扱い（新しいキャラクターが作られるかなど）も未確認です。

6技術的なリスク

リスクLaneBirmingham 版での対策残る問題
同時に更新したときの競合ロックをかけ、push する前にリモートが動いていないか確認する。統合（マージ）はしない片方の進行は捨てることになる
古いセーブでの上書きStart Hosting で常に最新を取得する。ロックの有効期限は24時間Start Hosting を押し忘れてゲームを起動すると防げない
ホスト交代のときの整合性世代番号とチェックサムで確認するキャラクターの入れ替えはしない
同期のタイミング手動のボタン操作だけ押し忘れると次の人に渡らない
セーブの破損上書きの前に zip でバックアップを取る（10個まで保持）。履歴から戻せる同期の対象が MoonSessions 全体になるので、ほかのスロットも巻き込む
Steam Cloud との競合対応する設定項目はあるが、Custom Folder では無効推測Steam Cloud が古い状態を書き戻してくる可能性がある
3人で使う場合collaborator として3人を招待できる全員が GitHub アカウントを作り、ツール類をインストールする必要がある

8おすすめ

  1. まずは SaveSync（¥700）Moon Sweepers に公式対応していて、キャラクターの入れ替えも機能に含まれています。使い方は SaveSync 日本語ガイドにまとめています。
  2. 無料にこだわるなら、LaneBirmingham 版を試す試す前に MoonSessions フォルダを手動でバックアップします。テスト用のワールドで、B がホストして A が参加したときにキャラクターがどうなるかを確かめます。
  3. 問題が出たら改造するか判断するキャラクターがずれる場合は、B 案（セーブ形式の解析と改造）に進むか、SaveSync に切り替えるかを決めます。
