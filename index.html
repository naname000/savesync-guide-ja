SaveSync でできること

すべて公式サイト・公式ガイドに書かれている機能です。

🔁

3人の誰でもホストになれる

セーブを共有しておけば、元のホストがオフラインでも、次は誰でもホストを担当できます。共有されたセーブを「Activate」すると、ホストは自動で切り替わります。

🧑‍🚀

自分のキャラクターのまま

ホストが変わっても、SaveSync がキャラクターを入れ替えます。前のホストも自分のキャラクターで参加できます（Moon Sweepers 対応）。

⏪

いつでも前の状態に戻せる

どのバージョンも自動でバックアップされます。いつ・誰が変更したかの履歴から、好きな版に戻せます。

📤

手作業のコピーは不要

セーブファイルを探して送り合う必要はありません。ホストはクリック1回でセーブをアップロードでき、そのあとは自動で同期されます。

🛡️

他人には見えない保存先

セーブは Steam ワークショップに暗号化された状態で、一覧に表示されない非公開設定で保存されます。アップロードとダウンロードの前には Windows Defender でスキャンされます。

🗂️

手持ちのワールドを上書きしない

共有されたワールドは空いているスロットに入るので、自分のほかのワールドは上書きされません。

💴

サーバー代なしの買い切り

有料の専用サーバーは不要です。SaveSync 本体は ¥700 の買い切りです（2026-11-17 時点の Steam 価格）。

😢 これまで

ワールドはホストした人のPCにしかありません。A がいない日は、B と C だけでは続きを遊べません。

➜

😊 SaveSync を使うと

最新のセーブを3人で共有できます。その日いるメンバーの誰かがホストになって、続きから遊べます。

ワールドを登録持ち主が + New Save → Create Save
友だちに共有共有アイコンから Steam ユーザー名で検索して Share
受け取って有効化友だちが Activate。これで誰でもホストになれる

詳しい手順は「最初の共有設定」、安全に使うコツは「セーブデータの競合」「運用ルール」へ。

2SaveSyncとは？

どんなソフト？

公式SaveSync は、協力プレイ（Co-op）のゲーム向けにセーブデータの同期・バックアップ・共有をするツールです。元のホストがいなくても、グループの誰もが続きから遊べるようにすることを目的としています。

  • 公式Steam で販売されています（買い切り）。早期アクセス中ですが、同期とホスト交代の機能はすでに使えます。
  • 公式Moon Sweepers は対応ゲームに入っています。
  • 公式対応 OS は Windows です（Linux は Proton 経由）。

なぜ必要なの？

公式Moon Sweepers のワールドは、ホストした人のPCの中にある5つのスロットのどれかに保存されます。ほかの人はコピーを持っていません。SaveSync はこのセーブを共有して、誰でもホストできるようにします（できることの一覧はページ上部）。

ゲーム内のマルチプレイとの違い

ゲーム内のマルチプレイSaveSync
役割みんなで同時に遊ぶための通信遊んでいない間にセーブデータを受け渡すための道具
セーブの場所ホストのPCだけSteam ワークショップ上に共有コピー（暗号化・非公開）
ゲームとの関係ゲームの機能公式ゲームの代わりにはならない。ゲームと一緒に使う

実際に一緒に遊ぶのは、これまでどおりゲーム内のマルチプレイです。SaveSync は「誰がホストしてもセーブを最新にしておく係」と考えると分かりやすいです。

  • 公式Moon Sweepers では、ゲームが「ホストのキャラクター」と「参加者のキャラクター（Steam ID ごと）」を分けて記録しています。別の人がホストになると、SaveSync が新しいホストに本人のキャラクターを割り当て、前のホストのキャラクターをその人の Steam ID 側に戻します。そのため前のホストも、自分のキャラクターのまま参加できます。
  • 公式セーブは Steam ワークショップに暗号化された状態で、一覧に表示されない非公開設定で保存されます。アップロードとダウンロードの前には Windows Defender でスキャンされます。

4最初の共有設定（1回だけ）

ここでは、今のワールドを持っている人を A、共有を受け取る人を B C として説明します。

⛔ SaveSync を操作するときはゲームを完全に終了しておく

公式SaveSync はゲームが起動していないときだけ動作します。SaveSync の操作は、必ず Moon Sweepers を終了してから行ってください。

A ワールドを SaveSync に登録する

  1. Moon Sweepers を完全に終了する
  2. SaveSync を開き、左のゲーム一覧から Moon Sweepers を選ぶ
  3. 右上の + New Save をクリックする
  4. 共有したいワールドを選んで Create Save をクリックする公式ゲーム内ではワールドに名前を付けられないため、ゲームのメニューと同じ内容（所持金・掃除済みの地域・プレイ時間）とスロット番号で表示されます。
  5. 同期が終わるまで待つ公式緑のチェックマークが出たら完了です。それまでは次の共有の手順に進まないでください。

A B と C に共有する

  1. セーブの行にある共有アイコンをクリックする
  2. 友だちの Steam ユーザー名で検索する
  3. 検索結果から友だちを選んで Share をクリックするB と C の2人に、それぞれ共有します。
⚠ 共有の取り消しについて

公式共有した相手は、セーブをダウンロードして自分のコピーとして持ち、変更することもできます。あとで共有を取り消しても、相手がすでに持っているコピーは消えません。共有するのは信頼できる友だちだけにしましょう。

B C 共有されたセーブを有効化する

  1. Moon Sweepers を終了した状態で SaveSync を開く
  2. Moon Sweepers の一覧に、A から共有されたセーブがあるか確認する
  3. Activate をクリックし、使うスロットを選んでもう一度 Activate をクリックする公式Moon Sweepers では空いているスロットに入るので、自分のほかのワールドが上書きされることはありません。
⚠ スロットが5つとも埋まっているとき

公式Moon Sweepers のスロット5つがすべて埋まっていると、有効化はできません。先に別のセーブを無効化（Deactivate）して、スロットを空けてください。

画面つきの手順：公式 Moon Sweepers ページ ／ 公式 Steam ガイド（Moon Sweepers） ／ 公式 Steam ガイド（全般）（いずれも英語）

5毎回の遊び方

最初の共有設定が終わったあと、毎回の遊び方です。

？ 同期がいつ行われるのかは未確認

公式「セーブは自動で同期される」とは書かれています。

未確認ただ、どのタイミングでアップロード・ダウンロードされるのか（ゲーム終了時か、SaveSync を起動したときか、常に裏で動いているか）は、公式の資料に書かれていませんでした。手動でアップロードするボタンがあるかも未確認です。

そのため下の手順では、SaveSync の画面で緑のチェックマークを目で確認することを毎回の決まりにしています。

  1. プレイ前：SaveSync を開いて最新の状態か確認するMoon Sweepers が終了していることを確かめてから SaveSync を開きます。セーブが同期済み（緑のチェックマーク）になっているか確認します。ルール同期中の表示なら、終わるまで待ちます。
  2. 今回のホストが Moon Sweepers を起動する今回ホストする人のPCで、そのセーブが有効化されている（スロットに入っている）ことを確認してから起動します。
  3. マルチプレイを開始するホストがワールドを開き、ほかの2人はゲーム内のマルチプレイで参加します。
  4. プレイを終えるゲーム内でセーブされたことを確認してから、Moon Sweepers を完全に終了します。
  5. SaveSync にアップロードされるのを待つホストが SaveSync を開き、セーブがアップロードされるのを待ちます（上の「未確認」のとおり、自動でアップロードされるタイミングは分かっていません）。
  6. 同期が終わったことを確認する緑のチェックマークが出ていれば完了です。必要なら、セーブ履歴でいちばん新しい記録が自分の名前・今の時刻になっているかも確認します。
  7. 次の人に引き継ぐルールDiscord で「同期完了」と報告します。これで、次は誰がホストしても続きから遊べます。
⛔ 同期が終わる前にPCをシャットダウンしない

アップロードが終わる前にPCを切ると、次の人が古いセーブで遊ぶことになりかねません。緑のチェックマークを確認するまではPCを切らないでください。

また、ホストではない参加者が SaveSync を起動しておく必要があるかどうかも未確認です。最初の回で実際に画面を見て確かめ、分かったことを3人で共有しておくと安心です。

7セーブデータの競合（いちばん大事）

⛔ 2つのセーブが自動で合体（マージ）されることは期待しない

公式SaveSync の利用規約には、同期によってセーブデータが上書きされたり失われたりすることがある（グループメンバー間の競合も含む）と書かれています。

未確認2人が別々に遊んだ場合に「両方の進行を統合する」のか「どちらか一方を選ぶ」のか、どちらが優先されるのか、警告が出るのか――といった競合時の動作は、公式の資料に書かれていませんでした。

推測マージ機能についての記述はどこにもありません。そのため、競合が起きたらどちらかの進行が失われる前提で運用するのが安全です。

公式頼りになるのはセーブ履歴です。いつ・誰がセーブを変更したかの履歴をすべて見ることができ、以前のバージョンに戻せます。

ケース1：A が遊んだあとに B が遊ぶ

どうなる
これが SaveSync の本来の使い方です。A が終了して同期が終わってから B が始めれば、B は A の続きから遊べます。
気をつけること
B は、A の同期が終わる（緑チェック・Discord 報告）まで待ってからゲームを起動します。

ケース2：A と B がそれぞれ別々に同じワールドを進めた

どうなる
未確認公式の資料に書かれていません。推測同じワールドから2つの未来に分かれるので、あとから同期された方が先の方を上書きし、片方の進行が失われるおそれがあります。
対処
セーブ履歴で両方の版を確認し、3人で話し合ってどちらの進行を残すかを決め、必要なら履歴から戻します。
予防
ルール同じワールドを遊ぶのは「ホスト宣言」をした1人だけにします。別々の時間にソロで遊びたいときは、共有ワールドではなく自分用の別ワールドを使います。

ケース3：同期を忘れてゲームを起動してしまった

どうなる
未確認公式の資料に書かれていません。推測手元にある古いワールドで遊び始めてしまうおそれがあります。
対処
気づいたらすぐにセーブせずに終了し、SaveSync を開いて同期の状態を確認します。遊んでしまった場合は Discord で報告し、あとから履歴で正しい版を選び直します。
予防
ルール「ゲームより先に SaveSync を開く」を習慣にします。

ケース4：古いセーブで上書きしてしまった

どうなる
新しい進行が古い版で上書きされた状態になります。
対処
公式セーブ履歴から、上書きされる前の版（誰が・いつ変更したかが表示されます）を選んで戻します（Revert）。戻したあとは、3人とも緑チェックを確認してから次のプレイを始めます。
未確認
未確認履歴が何世代・何日分残るかは公式の資料に書かれていません。気づいたら早めに戻しましょう。

ケース5：同期に失敗した

症状と原因
公式アップロードが 10%〜20% の間を行ったり来たりして終わらないことがあります。SaveSync は Steam ワークショップのサーバーを使ってアップロードしているため、Steam のダウンロード地域や配信経路が原因になることがあります。
公式の対処法
  1. SaveSync を閉じる
  2. Steam の「設定」→「ダウンロード」で、ダウンロード地域を次のどれかに変える：Singapore／Tokyo／Hong Kong／US – Seattle／US – Los Angeles
  3. Steam を再起動し、地域の設定が変わったままか確認する
  4. SaveSync を開いて、もう一度試す
それでもだめなとき
ルール同期できなかったことを Discord で報告し、解決するまでほかの人はそのワールドで遊ばないようにします。困ったときは公式 Discord（Steam ストアページからリンクされています）に相談できます。

83人の運用ルール（提案）

ℹ ここは SaveSync の機能ではありません

この章のルールは、事故を防ぐために3人で決める約束の提案です。SaveSync が自動でやってくれるものではありません。

基本ルール ルール

  1. ホストは1人だけ：遊ぶ前に Discord で「今から○○がホストします」と宣言する。宣言がない間は、誰も共有ワールドを起動しない。
  2. ゲームより先に SaveSync：起動する前に SaveSync を開き、緑チェックで最新になっていることを確認する。
  3. 終わったら同期完了まで見届ける：ゲームを完全に終了し、緑チェックが出るまでPCを切らない。
  4. 同期完了を報告：Discord で「同期完了」と書く。これが次のホストへのバトン。
  5. ソロで遊ぶときは別ワールド：共有ワールドを1人で進めたいときは、先に宣言する。勝手に進めない。
  6. おかしいと思ったらすぐ止める：進行が戻っている、知らない履歴がある、などに気づいたら遊ぶのをやめて Discord で相談する。

バックアップについて

  • 公式SaveSync はどのバージョンも自動でバックアップし、履歴から戻せます。
  • 公式それとは別に、利用規約では「失いたくないセーブは自分でも独立したバックアップをとっておくこと」を勧めています。
  • 未確認Moon Sweepers のセーブファイルがPCのどこに保存されているかは、SaveSync の公式資料に書かれていませんでした。手動でバックアップする場合は、ゲーム側の情報で保存場所を確認してください。
  • ルール大きく進めた日や、ボス戦・大きな買い物の前などは、セーブ履歴の版を Discord にメモしておく（例：「11/20 22時 B の版が正」）と、戻すときに迷いません。
